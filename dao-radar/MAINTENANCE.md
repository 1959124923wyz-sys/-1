# 道行四海｜维护清单

用于后续 ChatGPT 或人工维护时快速执行。

## 日常
由 GitHub Actions 自动完成，不需要人工操作。

## 全面内部监查
建议定期执行：

- [ ] 检查 GitHub Actions 是否成功
- [ ] 检查网站是否正常打开
- [ ] 读取完整 data.json
- [ ] 删除过期活动
- [ ] 删除报名已截止且无继续参与价值的活动
- [ ] 删除目录页/泛页面
- [ ] 删除低质量聚合来源
- [ ] 合并重复活动
- [ ] 检查国内来源
- [ ] 检查港澳台来源
- [ ] 检查海外来源
- [ ] 检查线上活动
- [ ] 检查论坛/课程/法会/展演/武术养生/征稿等类型是否失衡
- [ ] 主动搜索自动程序可能遗漏的重要活动
- [ ] 用官方原始链接替换二手来源
- [ ] 同一活动如有中文官方页，优先用中文页替换外文页；无中文官方页时保留外文原页
- [ ] 修复导致误收或漏收的后台规则
- [ ] 发布并验证网页

## 判断标准

“这条是否应该展示”的默认答案：

只要它是：
- 真实的；
- 与道教/道家明确相关；
- 当前仍可参加、旁听、报名、参观、投稿或持续跟踪；

就应该展示。

不要替使用者做能力或兴趣筛选。
