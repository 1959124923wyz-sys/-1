# 道行四海｜固定规则 v1.0

生效日期：2026-10-01

本文件是“道行四海”项目的最高维护规则。后续修改搜索脚本、数据、网页或人工审计时，以这里为准；除非明确更新版本，否则不要自行缩窄范围。

## 1. 项目目标

建立一个面向普通使用者、尤其适合长辈手机查看的“道教活动雷达”。

核心原则：

> 广泛收集，只排除已经过期、明显无关、重复和低质量垃圾信息。  
> 不替使用者判断“适不适合”，把选择权交给本人。

项目不是“精选推荐榜”，也不是只收国际交流。

## 2. 收录范围

### 中国大陆
- 中国道教协会、地方道教协会
- 宫观、道教学院、研究机构
- 法会、科仪、祈福、斋醮
- 玄门讲经、讲座、公开课
- 培训、研修、课程、招生
- 论坛、会议、研讨会、征稿
- 道教音乐、非遗、书画、展览、文化节
- 宫观开放活动、参访、巡礼
- 武当、太极、气功、养生等具有明确道教/道家背景的活动
- 国际交流、两岸交流、文化传播人才培训

### 港澳台
按与大陆相同的宽口径收录，另外重点关注：
- 宫庙与道教团体
- 道教学院
- 信俗文化
- 宗教文化节
- 公开法会与课程

### 海外
- 海外道教组织、宫观、基金会
- 大学与研究机构的道教学术活动
- 道教文化交流、论坛、会议
- Daoism / Daoist Studies 课程、静修、工作坊
- 有明确道家/道教传承背景的太极、气功、内丹等活动
- 中国哲学会议中明确覆盖 Daoism/Daoist/道家的项目

### 线上
- 线上讲座、课程、研讨会
- 在线静修、修习课程
- 在线征稿、论文征集
- 公开直播与网络文化交流

## 3. 不因以下原因自动排除

- 活动偏学术
- 需要英文
- 需要一定专业背景
- 规模较小
- 地点偏远
- 可能收费
- 可能只适合道教界人士
- 可能只适合普通公众
- 用户本人是否具备资格尚不明确

如主办方原文有资格限制，保留活动，由使用者自行判断。

## 4. 必须排除

- 已明确结束且没有后续参与价值的活动
- 报名截止且无法再参与的单次活动
- 纯粹的活动回顾、新闻报道
- 与道教/道家无明确关系的泛宗教或泛传统文化内容
- 同一活动的重复转载
- 搜索结果目录页、活动总目录页本身
- 低质量聚合页、商业SEO页、明显抄袭页
- 无法确认活动存在的可疑信息

## 5. 过期规则

优先使用：
1. 报名截止日期
2. 活动结束日期
3. 官方明确说明的最后参与日期

有明确日期：
- 到期后自动退出。

没有明确日期：
- 自动搜索条目若连续 60 天不再被搜索发现，自动退出。
- “筹备中”的重大活动可以人工设置较长有效期，但必须定期复核。

长期课程：
- 只要课程仍在进行，继续保留。
- 即使报名已经结束，只要仍允许旁听、开放日、后续批次或公众参与，可保留并在摘要中说明。

## 6. 信息源优先级

优先顺序：

1. 主办方官网 / 官方活动页
2. 中国道教协会、地方道协、宫观、道教学院
3. 政府宗教事务、文化机构、高校官网
4. 官方基金会、协会、学术组织
5. 可信媒体或专业道教文化网站
6. 活动报名平台

尽量不使用：
- 商业聚合站
- SEO目录站
- 无法确认主办方的转载站

如果只能通过二手来源发现活动，后续应尽量寻找原始来源替换。

## 7. 去重规则

同一活动只展示一次。

优先保留：
- 官方原始页面
- 信息更新更及时的页面
- 日期、报名方式更完整的页面

不要因为不同转载链接而重复展示。

## 8. 网页展示规则

坚持“低阅读压力”。

每张卡片只保留：
- 地区
- 活动名称
- 活动类型
- 活动时间
- 截止日期（如有）
- 1—2句中文说明
- 原文链接

不加入：
- 复杂评分
- 长篇AI评价
- 大段原文复制
- 复杂统计图
- 过多筛选条件

分类固定为：

> 最新｜国内｜港澳台｜海外｜线上

字体保持适合长辈阅读，大按钮，高对比度。

## 9. 自动化原则

GitHub Actions 每日自动运行。

自动流程：
搜索 → 判断未过期 → 去重 → 简短中文整理 → 更新 data.json → 自动发布网页。

目标：
- 日常无需人工操作
- 不调用 ChatGPT/OpenAI API
- 尽量保持零额外 token 成本

## 10. 人工维护 / ChatGPT内部审计

自动搜索只能负责日常增量，不能替代人工审计。

人工审计时至少检查：

1. 当前条目是否有过期内容
2. 是否出现重复活动
3. 是否出现目录页、聚合页、低质量来源
4. 国内 / 港澳台 / 海外 / 线上是否明显失衡
5. 是否遗漏大型道教论坛、道协活动、宫观活动、课程和征稿
6. 重点来源是否有新活动未被搜索器抓取
7. 日期解析是否正确
8. 原文链接是否仍有效
9. GitHub Actions 最近是否正常运行
10. GitHub Pages 是否正常发布

发现问题时：
- 能直接修复的直接修复
- 同时修改后台规则，避免同类问题再次出现
- 不只修改单条数据

## 11. 重点维护方向

当前最大短板：

> 中国大陆前瞻活动发现能力。

原因：
大量活动优先发布在地方道协、宫观、公众号、临时公告和海报，而搜索引擎经常在活动结束后才收录。

因此后续优先建设：
- 中国大陆重点道协固定来源
- 重点宫观固定来源
- 道教学院固定来源
- 地方民族宗教部门
- 道教文化专业媒体

海外继续保持官方机构、大学、Daoist Foundation、Daoist Gate、Wudang、学术协会等来源。

## 12. 维护原则

每次修改遵守：

> 先保护覆盖面，再提高准确度。

不要因为少量误收就把规则收得过窄。

宁可保留一个可能适合的真实未来活动，也不要因为无法判断用户能力而自动删除。

但过期、重复、低质量信息必须清理。
