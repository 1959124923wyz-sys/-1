# 道行四海｜固定规则 v1.6

生效日期：2026-10-01

本文件是“道行四海”项目的最高维护规则。后续修改搜索脚本、数据、网页或人工审计时，以这里为准；除非明确更新版本，否则不要自行缩窄范围。

## 1. 项目目标

建立一个面向普通使用者、尤其适合长辈手机查看的“中华传统文化交流机会雷达”。

当前第一优先目标：

> 帮助有道教背景的中国人士发现“走出去”的现实入口——赴海外传播道教、中医药、太极气功、养生、道教音乐/非遗及相关中华文化。

原有广泛道教活动雷达继续保留。前台把“低门槛”设为默认重点视图，其次是“出海机会”；大型机构、高门槛岗位继续保留但不挤占低门槛机会的发现优先级。

核心原则：

> 广泛收集，只排除已经过期、明显无关、重复和低质量垃圾信息。  
> 不替使用者判断“适不适合”，把选择权交给本人。

项目不是“精选推荐榜”。广泛活动继续收录，但“出海机会”机会优先发现、优先人工核验、优先展示。

### 低门槛出海：最高搜索优先级
“低门槛”按机会本身公开写出的正式要求判断，不按任何具体个人背景判断。优先收集：
- 不要求本科/硕博、论文、专业职称、官方推荐单位的公开机会
- 只要求年龄、兴趣、一般经验、作品/演示视频、简单证书的机会
- 社区中心、休闲中心、老年中心、图书馆、学校、中文学校的兼职/临时/按课时老师
- 华人社团、宗亲会、商会、唐人街机构、民间文化协会的讲座、顾问、志愿者、活动嘉宾
- 春节/中秋/亚洲文化节的表演者、工作坊、文化摊位、志愿者公开招募
- 道观、道教团体、养生馆、太极/气功馆、静修中心的小型合作、驻点、客座、助教或志愿机会
- 中医药科普、养生文化、太极气功的社区讲座和体验活动
- 自费、无偿、短期机会也可收录，只要是真实的海外交流入口；必须清楚标注“无报酬/无差旅”或“签证需自理”

“正式准入门槛低”与“能否取得目标国签证/工作许可”分开判断。一个岗位可以是低学历门槛，但不提供签证赞助；仍可收录，并在摘要注明。

### 出海机会的判定
符合下列任一情况即可进入“出海机会”：
- 海外会议、论坛、文化节可报名参加并建立合作
- 可投稿、做视频报告、申请演讲或工作坊
- 可参展、展示中医药/道教/非遗/养生成果
- 海外机构明确接待 visiting teacher / visiting Daoist teacher / guest lecturer
- 海外中医学院、文化中心、道教组织有专家讲座、英文公众课、定制活动合作入口
- 中外机构合作、宫观结对、海外教学点、文化交流团
- 明确的海外业务交流、实地访问、机构考察
- 面向海外公众的线上传播、英文课程或国际出版/投稿
- 孔子学院、国际中文教育志愿者、国家公派出国教师、海外华文学校等海外任教岗位
- 海外中文学校/文化中心招聘武术、太极、书法、国画、音乐、中华文化类教师
- 海外道观、道教协会、道文化机构招聘或邀请道士、驻点教师、客座讲师、顾问
- 海外中医学院、大学、医院、研究机构招聘中医讲师、针灸师、访问教授、客座教师
- 华人社团、宗亲会、商会、民间文化团体邀请中华文化顾问、讲师、活动嘉宾
- 短期驻点、访问学者、文化志愿者、国际志愿服务、海外夏令营/冬令营带队或授课
- 任何能合法赴海外进行讲课、演示、参访、合作、任职、顾问、驻点或文化传播的现实入口

对“叔叔是否满足资格”不做前置筛选。即使岗位要求学历、语言、执业注册、年龄或推荐单位，也先收录并在摘要里写清限制。

对中医药机会要区分“文化教育/养生传播”和受当地法律监管的临床医疗行为；网页不推定任何人的执业资格。

## 2. 收录范围

### 中国大陆
- 中国道教协会、地方道教协会
- 宫观、道教学院、研究机构
- 法会、科仪、祈福、斋醮
- 玄门讲经、讲座、公开课
- 培训、研修、课程、招生
- 论坛、会议、研讨会、征稿
- 道教音乐、非遗、书画、展览、文化节
- 宫观开放活动、参访、巡礼
- 武当、太极、气功、养生等具有明确道教/道家背景的活动
- 国际交流、两岸交流、文化传播人才培训

### 港澳台
按与大陆相同的宽口径收录，另外重点关注：
- 宫庙与道教团体
- 道教学院
- 信俗文化
- 宗教文化节
- 公开法会与课程

### 海外
- 海外道教组织、宫观、基金会
- 大学与研究机构的道教学术活动
- 道教文化交流、论坛、会议
- Daoism / Daoist Studies 课程、静修、工作坊
- 有明确道家/道教传承背景的太极、气功、内丹等活动
- 中国哲学会议中明确覆盖 Daoism/Daoist/道家的项目

### 文化交流与机构合作
- 世界道教联合会、中国道教协会及海外全国性/地区性道教组织的交流项目
- 东西道教合作、友好宫观/友好机构结对
- 宫观互访、参访、谒祖、朝宗、研学
- 港澳台与内地道教界联谊、宫观交流
- 中外道教团体互访、联合展演、文化考察
- 道教与其他宗教、文明之间的对话活动
- 长期合作项目即使没有“公开报名”，只要存在明确合作入口或可联系主办机构，也可作为“持续跟踪/合作线索”收录

### 教务与道教人才
- 全真传戒、正一授箓、冠巾、传度、皈依等公开或可申请教务活动
- 境外道教教职人员身份认定及相关申请渠道
- 道教学院、国际道教文化研修班、国际交流人才培训
- 宫观管理、斋醮科仪、道教音乐、道医、武术等专业培训

### 非遗、艺术与文化传播
- 道教音乐、科仪音乐、非遗展演
- 道教书画、碑拓、摄影、展览
- 《道德经》书法、征文、歌唱、歌曲创作等比赛
- 道教主题出版、翻译、数字人文、经典海外传播
- 道教文化节、道教日、庙会、信俗文化节

### 青年与公众传播
- 道文化体验周、夏令营、青年研学
- 面向学校、青年、普通公众的道教文化教育活动
- 公开讲座、体验课、文化工作坊

### 线上
- 线上讲座、课程、研讨会
- 在线静修、修习课程
- 在线征稿、论文征集
- 公开直播与网络文化交流
- 高校慕课 / 国家级在线课程 / 学堂在线 / 智慧树等公开课程
- 实体+线上同步的混合课程（Zoom、Google Meet、腾讯会议等）
- 系列读书会、长期网课、公开课
- 宫观、道教团体或高校的直播讲经、直播论坛与直播文化活动

特别注意：中国大陆和台湾的“线上活动”经常不会使用“线上活动”这个标题，而会写成“慕课、公开课、直播、同步课程、读书会、网课、线上共修、Google Meet、Zoom、腾讯会议”等形式，搜索时必须覆盖这些表达。

## 3. 不因以下原因自动排除

- 活动偏学术
- 需要英文
- 需要一定专业背景
- 规模较小
- 地点偏远
- 可能收费
- 可能只适合道教界人士
- 可能只适合普通公众
- 用户本人是否具备资格尚不明确

如主办方原文有资格限制，保留活动，由使用者自行判断。

## 4. 必须排除

- 已明确结束且没有后续参与价值的活动
- 报名截止且无法再参与的单次活动
- 纯粹的活动回顾、新闻报道
- 与道教/道家无明确关系的泛宗教或泛传统文化内容
- 同一活动的重复转载
- 搜索结果目录页、活动总目录页本身
- 低质量聚合页、商业SEO页、明显抄袭页
- 无法确认活动存在的可疑信息

## 5. 过期规则

优先使用：
1. 报名截止日期
2. 活动结束日期
3. 官方明确说明的最后参与日期

有明确日期：
- 到期后自动退出。

没有明确日期：
- 自动搜索条目若连续 60 天不再被搜索发现，自动退出。
- “筹备中”的重大活动可以人工设置较长有效期，但必须定期复核。

长期课程：
- 只要课程仍在进行，继续保留。
- 即使报名已经结束，只要仍允许旁听、开放日、后续批次或公众参与，可保留并在摘要中说明。

## 6. 信息源优先级

优先顺序：

1. 主办方官网 / 官方活动页
2. 中国道教协会、地方道协、宫观、道教学院
3. 政府宗教事务、文化机构、高校官网
4. 官方基金会、协会、学术组织
5. 可信媒体或专业道教文化网站
6. 活动报名平台

尽量不使用：
- 商业聚合站
- SEO目录站
- 无法确认主办方的转载站

如果只能通过二手来源发现活动，后续应尽量寻找原始来源替换。

### 中文页面优先
对于同一个活动，在真实性、时效性和官方程度相当的前提下，来源语言优先级固定为：

1. 中文官方活动页
2. 中文主办方公告 / 中文报名页
3. 外文官方活动页
4. 外文可信二手来源

如果已有英文官方页，后续发现同一活动的中文官方页，应把网页链接替换成中文页；英文页可作为内部核验来源，但前台默认不重复展示。
如果没有同一活动的中文正式页面，则保留外文官方页，不为了“中文化”而换成低质量转载。

## 7. 去重规则

同一活动只展示一次。

优先保留：
- 官方原始页面
- 信息更新更及时的页面
- 日期、报名方式更完整的页面

不要因为不同转载链接而重复展示。

## 8. 网页展示规则

坚持“低阅读压力”。

每张卡片只保留：
- 地区
- 活动名称
- 活动类型
- 活动时间
- 截止日期（如有）
- 1—2句中文说明
- 原文链接

不加入：
- 复杂评分
- 长篇AI评价
- 大段原文复制
- 复杂统计图
- 过多筛选条件

分类固定为：

> 低门槛｜出海机会｜最新｜国内｜港澳台｜海外｜线上

字体保持适合长辈阅读，大按钮，高对比度。

## 9. 自动化原则

GitHub Actions 每日自动运行。

自动流程：
搜索 → 判断未过期 → 去重 → 简短中文整理 → 更新 data.json → 自动发布网页。

目标：
- 日常无需人工操作
- 不调用 ChatGPT/OpenAI API
- 尽量保持零额外 token 成本

## 10. 人工维护 / ChatGPT内部审计

自动搜索只能负责日常增量，不能替代人工审计。

人工审计时至少检查：

1. 当前条目是否有过期内容
2. 是否出现重复活动
3. 是否出现目录页、聚合页、低质量来源
4. 国内 / 港澳台 / 海外 / 线上是否明显失衡
5. 是否遗漏大型道教论坛、道协活动、宫观活动、课程和征稿
6. 重点来源是否有新活动未被搜索器抓取
7. 日期解析是否正确
8. 原文链接是否仍有效
9. 同一活动是否存在更合适的中文官方页面；若有则优先替换
10. GitHub Actions 最近是否正常运行
11. GitHub Pages 是否正常发布

发现问题时：
- 能直接修复的直接修复
- 同时修改后台规则，避免同类问题再次出现
- 不只修改单条数据

## 11. 重点维护方向

当前两大短板：

> 1. 中国大陆前瞻活动发现能力。
> 2. 分散在大学招聘页、孔子学院通知、海外协会/道观官网、华人社团和民间机构里的“出海任教/顾问/招聘”机会。
> 3. 最容易被普通搜索忽略的社区级、民间级、兼职、志愿、表演、工作坊等低门槛入口。

原因：
大量活动优先发布在地方道协、宫观、公众号、临时公告和海报，而搜索引擎经常在活动结束后才收录。

因此后续优先建设：
- 中国大陆重点道协固定来源
- 重点宫观固定来源
- 道教学院固定来源
- 地方民族宗教部门
- 道教文化专业媒体

海外继续保持官方机构、大学、Daoist Foundation、Daoist Gate、Wudang、学术协会等来源。

低门槛来源必须额外覆盖：地方政府/公园休闲部门、社区中心、老年中心、图书馆、博物馆、中文学校、华人协会、唐人街组织、文化节主办方、社区医疗/养生机构、太极气功馆、静修中心、活动报名页和志愿者平台。搜索要同时使用英语及日/韩/德/法/西等当地语言关键词。

平台型来源（Eventbrite、Meetup、VolunteerMatch、Idealist、Workaway及公开社交页面）可用于“发现线索”。若找到主办方官网、直接报名表或招聘原页，前台优先换成直接来源；如果没有更好的来源但平台页面本身就是直接公开申请入口，可保留。

## 12. 维护原则

每次修改遵守：

> 先保护覆盖面，再提高准确度。

不要因为少量误收就把规则收得过窄。

宁可保留一个可能适合的真实未来活动，也不要因为无法判断用户能力而自动删除。

但过期、重复、低质量信息必须清理。
