# 道行四海

给长辈使用的道教文化交流机会网页。

## 平时怎么工作

每天 08:30（Asia/Taipei）GitHub Actions 自动：

1. 搜索中文、英文、日文、韩文的道教/道家交流信息；
2. 只保留同时包含道教主题和“会议、论坛、交流、讲座、征稿、报名”等机会特征的结果；
3. 自动去重；
4. 外文标题和摘要尽量自动翻成中文；
5. 写入 `site/data.json`；
6. 自动重新发布 GitHub Pages。

这个流程不调用 ChatGPT API，所以日常运行不消耗 ChatGPT token，也不需要 API Key。

## 通常不需要做任何事

网页只读取 `site/data.json`。自动任务失败时，旧网页仍可正常打开，只是当天不会增加新信息。

## 手动运行

GitHub → Actions → “道行四海每日更新” → Run workflow。

## 说明

自动搜索属于“机会雷达”，可能偶尔出现无关或信息不完整的条目，因此网页始终保留“查看原文”按钮，以原网站为准。
