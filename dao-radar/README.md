# 道行四海

给长辈使用的“道教活动雷达”。

## 收录原则

现在采用“广覆盖”：

- 国内宫观、道教协会、道教学院活动
- 法会、科仪、讲经、讲座
- 培训、课程、研修、招生
- 论坛、会议、征稿、学术活动
- 道教音乐、非遗、书画、展览、文化节
- 武当、太极、气功、养生等明确带有道教/道家背景的活动
- 港澳台道教活动
- 海外道教组织、高校和国际文化交流
- 线上活动

只自动排除：
1. 已经过期；
2. 明显无关；
3. 重复条目；
4. 明显低质量的聚合/转载页。

不再替使用者判断“是否适合”，选择权留给本人。

## 自动运行

每天 08:30（Asia/Taipei）GitHub Actions 自动：

1. 用中、英、日、韩关键词广泛搜索；
2. 判断是否仍在进行或未来可参与；
3. 自动识别地区与活动类型；
4. 自动去重；
5. 外文标题和摘要尽量转成中文；
6. 更新 `site/data.json`；
7. 若 GitHub Pages 已启用则自动发布网页。

不调用 ChatGPT/OpenAI API，不需要 API Key，因此日常运行不消耗 ChatGPT token。

## 数据保鲜

- 有明确截止日/结束日的条目，到期后自动删除。
- 没有明确日期的自动搜索条目，如果 60 天内不再被搜索到，会自动退出。
- 手工核实的重点活动也设置有效期，避免长期残留。

## 网页

前台只显示：活动名称、地区、类型、日期、简短说明和原文链接。

分类：最新 / 国内 / 港澳台 / 海外 / 线上。
