# 数据来源与口径

本项目把“数据来源”和“地图坐标来源”分开处理：

- **当前/近期参考价格**：优先读取房天下小区详情/小区攻略页；个别已核对小区可用 58 同城作为优先或备用来源。价格字段是挂牌/参考均价，不是成交价。
- **小区发现目录**：`https://sz.esf.fang.com/housing/`。自动任务按少量页面分批扫描，遇到异常即停，不绕过验证码或限流。
- **坐标缓存**：公开 GitHub 项目 `Qixuan5/data_analysis` 中的深圳历史链家地理编码快照，仅用于“名称 → 坐标”匹配。旧价格字段不会进入本项目当前价格。
- **地图底图**：OpenStreetMap 标准瓦片，并保留署名。

自动抓取并不等同官方 API。任何来源都可能改版、限流或延迟，因此页面会显示数据期与刷新失败数；刷新失败时保留上一次成功值。
