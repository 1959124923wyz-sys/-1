# 墨尔本 · 攀岩馆地图

一个面向 **Greater Melbourne + 周边（含 Geelong 边缘）** 的公开攀岩设施地图。项目延续深圳“攒房地图”的思路：静态网页、GitHub Pages 托管、无需付费 API Key，并把“数据事实”和“地图展示”分开维护。

## V1 收录口径

默认收录四类设施：

- 传统攀岩馆：抱石、顶绳、先锋、速度、自动保护等；
- 亲子 / 娱乐攀岩：例如 Clip 'n Climb、Climb N' Play，和运动攀岩馆分开标识；
- 公共免费人工抱石墙；
- 即将开放、已宣布关闭日期、运营状态需关注的场馆，使用独立状态而不是伪装成“正常营业”。

营业时间、票价、设施、年龄限制与运营状态优先来自场馆官网。data/seed.json 是经过人工核对的事实主库。

## 为什么不是“全自动爬所有网站”

攀岩馆没有统一的公开 API。价格、营业时间和临时闭馆信息分散在不同官网、预订系统和社交媒体。自动抓取 HTML 很容易把旧活动页、节假日页面或搜索摘要误写成“当前事实”。

因此本项目采用保守的混合策略：

1. **官方来源维护事实主库**；
2. **Nominatim** 仅为缺失地址做一次性/缓存式地理编码；
3. **OpenStreetMap Overpass** 只发现候选点，写入 data/osm_candidates.json，不会自动发布；
4. 自动任务每天检查来源 URL 是否仍可访问，并重建前端数据；
5. 网络失败时保留旧坐标和旧候选，不清空已有数据。

## 地图实现

前端没有使用 Leaflet / Mapbox / Google Maps 等 JS SDK，而是内置了一个轻量 Web Mercator 滑动地图：

- OSM 标准瓦片只负责道路/城区背景；
- 场馆坐标和筛选逻辑全部由本站代码渲染；
- 瓦片加载失败时，底层会退化为网格背景，但场馆点位、筛选和列表仍可用；
- 点位尺寸不随缩放变大/变小；
- 缩放到较高层级后逐步显示场馆标签，悬停和选中始终显示标签。

> OSM 公共瓦片适合本项目当前这种低流量公开展示。如果将来出现较高访问量，应按 OpenStreetMap tile usage policy 切换到自有或商业瓦片服务。

## 自动更新

工作流：.github/workflows/melbourne-climbing-refresh.yml

脚本：scripts/update_gyms.py

自动生成：

- data/gyms.json
- data/gyms.js
- data/geocode_cache.json
- data/osm_candidates.json

定时任务每天运行一次，也可以在 GitHub Actions 手动执行。

## 数据字段

每个场馆至少包含：

- 名称 / suburb / 地址
- 坐标
- 设施类型与攀岩项目
- 运营状态
- 成人参考日票（仅在有可靠来源时填写）
- 结构化常规营业时间
- 年龄 / 监管提示
- 官方或主要来源 URL
- 人工核对日期
- 说明与异常状态

网页中的“现在营业”按 Australia/Melbourne 时区计算，只适用于有结构化常规营业时间的场馆，不能覆盖临时活动、节假日和特殊闭馆。

## 本地运行

由于网页会 fetch() 数据文件，建议不要直接双击 HTML，而是在项目目录运行：

    python -m http.server 8000

然后打开 http://localhost:8000/ 。
